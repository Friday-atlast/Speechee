# Speechee Documentation

Welcome to the Speechee documentation.

Speechee is an **offline-first Speech-to-Text (STT)** system built around **whisper.cpp** (C++) and a **Python** wrapper, with:

- A CLI (`speechee`) for recording, file transcription, and model/config management
- A REST API (FastAPI) with an optional lightweight Web UI
- Utilities for audio preprocessing, language detection (including Hinglish heuristics), and performance monitoring
